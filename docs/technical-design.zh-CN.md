# NSUID Mapper 技术设计

## 职责与结构

这是独立的跨区商品编号映射库，只依赖 JavaScript / Web API，不依赖其他 Savanna 客户端。它不保存商品资料、不提供 HTTP 服务，也不内置数据库或缓存。

`src/index.ts` 是唯一支持的包入口。导出范围与迁移方式见 [README](../README.md#public-exports)。经实际调用检查，`fetchIdentities` 和 `mapInto` 用于复用身份并逐国处理失败，保留为高级接口；其他内部辅助函数仍可在库内引用，不再全部从根入口公开。测试可直接引用内部模块，避免仅为测试而增加公共 API。

- `src/client.ts`：公开方法、参数校验和目标国家并发调度。
- `src/mapping.ts`：本体、DLC、合集的匹配决策。
- `src/upstreams/savanna.ts`：必要的 GraphQL 查询、身份标准化和关联项分页。
- `src/upstreams/redirector.ts`：Nintendo Apps Redirector 请求和跳转解析。
- `src/request.ts`：两套上游共用的请求执行器，统一预算、取消检查、重试循环及响应体释放；具体响应解析留在各上游模块。
- `src/retry.ts`：两个上游共用的重试次数校验、指数退避、Retry-After 解析和可取消等待；不增加公开函数导出。
- `src/headers.ts`：统一大小写不敏感的请求头合并，后传入的值覆盖前面的值。
- `src/timeout.ts`：两个上游共用的超时参数校验，接受 1–120000 的整数毫秒，默认 10000。

输入一个 NSUID、源国家和最多 8 个目标国家，返回源身份和每个目标国家的 `nsuid` 或未映射 `reason`。不比较名称、发行商名称或文案相似度。

```ts
const result = await mapper.mapNsuid('70070000039411', {
  from: 'US',
  to: ['JP', 'GB'],
});
```

NSUID 是地区商品编号；Application ID 是内容锚点，但不能单独保证两个商品是同一版本。本体与 Switch 2 Edition 可以共用 AppID，多权益 DLC 也不能只靠第一个权益描述全部内容。

## 本体与 DLC

**本体**：从源商品读取 AppID、`labelPlatform` 和全部 `romRights.titleId`，先检查证据是否齐全；缺失时直接返回原因，不发起目标国家请求。Redirector 返回的商品只是入口，继续读取它及 `upgradeInfo` 关联的基础版 / 升级版身份；关联版本的身份嵌套在同一次查询里返回，不再单独请求。只有 AppID、平台、完整权益集合都一致且仅有一个候选时才返回映射。

**DLC**：读取平台与全部 `romRights.titleId`，对所有权益推导父应用编号并去重。解析目标父商品，分页读取其 DLC 列表及首页的 `upgradeInfo.upgradeDlcItem`，比较平台与完整权益集合。相同 NSUID 在两条路径重复出现时只算一个候选；不同 NSUID 都匹配时返回歧义原因。权益顺序、大小写和重复 ID 不影响比较。扫描未完成时，不接受此前找到的候选。

DLC 也限制最多 16 个父应用候选，通常所有权益只指向同一个父应用。缺少平台 / 权益、权益不是有效应用编号或没有目标父商品时返回未映射原因。

完整权益集合仍不保证商品唯一。日区 `70050000072881`–`70050000072884` 是四个不同 DLC，但均为 BEE、单一权益 `0400a3a01ee4d001`；美、英、澳、港区各自的四条同级 DLC 也共用这些字段。本库对此返回歧义，不按名称、编号邻近程度或排列顺序挑选。公开 client 不接受 `DlcItem.itemId`，不能直接套用消耗品的字段。

同款本体的跨区 AppID 也可能不同：怪猎崛起日港版为 `0100559011740000`，欧美澳版为 `0100b04011742000`；两组各自可解析，但没有公开、已核实的跨组关联。本库保留各组身份，不按同名合并。

`resolveNsuidsToAppIds` 使用更小的独立查询，只返回编号，不读取合集成员。该方法的单个 ID 返回值也不表示完整商品身份。

## 体验版：通过所属本体

体验版没有 `applications`，也没有 `romRights`，公开接口里唯一的锚点是它与本体的关系（2026-10-14 实测）：

- 源身份查询读取 `DemoItem.targetApplicationItems`（必须带 `salesStatuses`，否则返回 400），得到所属本体的完整身份及其 `demoItems`。
- 每个所属本体按本体规则映射到目标区，目标本体的 `demoItems` 即候选。两个字段都并入已有的身份查询，请求数与本体映射相同。
- 源本体与目标本体在体验版所属平台都必须恰好列出一个体验版，才接受结果；任一侧有多个同平台体验版时返回歧义，不按名称或顺序挑选。
- 多个所属本体得到不同的目标体验版时同样返回歧义；所属本体无法映射或目标本体未列出体验版时返回对应原因。

这比权益比较弱：证据是“所属本体身份一致 + 平台一致 + 两侧唯一”，不是体验版自身的编号。7001 编号的免费体验版 / 好友通行证是本体，仍走本体规则。

## 合集：完整身份与唯一候选

### 1. 源身份

读取合集自身的：

- `labelPlatform`
- 全部 `romRights.titleId`
- `itemsV2(publicStatuses: [PUBLIC, UNSEARCHABLE])`

每个成员至少读取 `__typename`。支持的成员进一步读取：

| 成员类型           | 身份字段                                                          |
| ------------------ | ----------------------------------------------------------------- |
| `ApplicationItem`  | `labelPlatform`、全部 `applications.id`、全部 `romRights.titleId` |
| `DlcItem`          | `labelPlatform`、全部 `romRights.titleId`                         |
| `ConsumableItemV2` | `itemId`、`consumableItemGroup.publisher.id`                      |

应用 / 权益 ID 去空白、转小写、去重并排序。应用和 DLC 成员形成包含“类型、平台、应用 ID 集合、权益集合”的规范签名；消耗品成员形成包含“类型、发行商 ID、itemId”的签名。全部成员签名排序后比较，保留重复成员的数量。地区 NSUID、名称和成员排列顺序不参与身份比较。

`itemId` 是不透明字符串，保留原值和大小写，不去空白或解析其中的单词；空白字符串视为缺失。发行商 ID 必须是正的安全整数。合集的父应用、平台和完整权益也必须匹配，不单独依赖 `itemId` 的全局唯一性。`consumableItemGroup.id` 不参与比较：NBA 2K26 的分组 ID 随地区变化，但对应成员的 `itemId` 和发行商 ID 相同。源身份和候选身份共用这组最小字段查询，不读取消耗品文案、价格或分组详情。

`contentAppIds` 是全部成员应用 / 权益编号的并集，仅用于发现父应用；`contentKeys` 是用于比较的成员签名列表。两者都是本库生成的元数据，不是上游字段。

### 2. 候选发现

1. 从所有成员 ID 推导父应用 ID，去重后逐个通过 Redirector 获取目标父商品。
2. 分页读取目标父商品的关联合集，合集的完整身份随列表一起返回；首页同时读取 `includedBundleItems`。DLC 条目只保留类型名用于计算分页偏移，不读取其平台和权益。
3. 沿 `upgradeInfo` 中的基础版和升级版链接继续读取父商品，避免只找到基础版的合集。
4. 合集按编号去重。
5. 扫描完所有可达父商品，比较合集平台、完整权益和成员签名。仅一个匹配才返回结果；多个匹配返回歧义原因。

成员与关联项均包含 `UNSEARCHABLE`，避免漏掉地区之间公开状态不同、但实际携带订阅时长或附加权益的商品。销售状态筛选使用已确认合法的 `ONSALE`、`PRE_ORDER`、`SALES_TERMINATION`、`UNRELEASED`。

### 3. 无法可靠匹配的情况

- 合集没有平台、权益或成员。
- 成员缺少平台 / 权益，或本体成员缺少应用 ID。
- 消耗品成员缺少有效的 `itemId` / 发行商 ID，或成员类型尚不支持。
- 完整匹配的候选不止一个。
- 父商品扫描或分页触及上限。
- 空页返回时，已扫描数量仍小于上游声明的 `total`。
- 上游关联列表未暴露目标商品，例如已确认的 `NOT_SALE` 合集。

以上返回未映射原因，不忽略缺失成员、不选第一个匹配，也不回退到普通版本。消耗品分组 ID 在地区间可能不同，不能当通用跨区外键；名称同样不能作为兜底。

DLC / 合集的父 AppID 没有目标跳转时跳过，候选范围限定为成功解析的父商品。完整身份比较仍包含全部权益 / 成员，不因父跳转缺失删减字段。接受的是这个范围内的唯一匹配，并不保证全地区目录唯一；父商品或分页扫描触及上限、提前空页造成未完成时仍拒绝部分结果。请求超时、网络、权限或 schema 错误不会被当成“无跳转”跳过。

## 请求成本和边界

- 最多 8 个目标国家并发；同一个国家的父商品串行扫描。
- 每个国家最多扫描 16 个父商品；关联项每页 100 条，每个父商品最多 40 页。
- 合集的完整身份随父商品关联列表一起返回，不再分批单独查询。2026-10-15 对 US/GB/JP/HK 共 242 个父商品、679 个合集比对，结果与分批查询逐字段一致，请求约减半，响应总量略降（合集编号不再重复传输）。
- 本体的目标查询把 `upgradeInfo` 关联版本的身份嵌套返回；同日对 126 个带关联版本的本体比对，结果一致，每个国家少 1 次请求。
- 每个国家的请求数：本体及体验版为 Redirector 1 次 + 身份 1 次；DLC 为每个父应用 Redirector 1 次 + 每 100 条一页；合集为每个父应用 Redirector 1 次 + 每个父商品（含关联版本）每 100 条一页。源身份请求只在开始时发 1 次。
- 达到上限且扫描未完成时，不接受此前找到的 DLC 或合集候选。若最后一页刚好完成扫描，不视为截断。
- 提前空页停止请求，标记扫描未完成，并给出区别于分页上限的原因；`total: 0` 的空页正常完成。此异常通过真实身份字段构造响应验证，本次线上正常分页未出现。
- `upgradeInfo` 仅在每个父商品首页选择；DLC 模式读取升级包身份，合集模式读取关联父商品编号。合集完整身份随列表返回，不删减用于准确匹配的字段。
- 独立消耗品没有本库用于发现目标父商品的应用编号，返回原因。消耗品 `itemId` 可用于合集内成员匹配，但没有按 `itemId` 查询其他地区商品的入口。
- 身份查询在 `itemsV2` 公共层选择 `__typename`、`nsUid`。已存在但不支持映射的兑换券 / 课程券返回 `kind: 'unknown'` 和包含实际类型名的原因，不再误报商品未找到。未由 `itemsV2` 返回的订阅券仍无法识别。
- 上游请求失败通过 `NsuidMapError` 抛出；业务上的未映射通过 `reason` 返回。单个国家出现硬错误仍会使本次调用拒绝，没有改为部分成功协议。
- Savanna 和 Redirector 默认单次请求总超时 10 秒，最多额外重试 2 次。`retries` 同时控制两个上游，支持构造默认值与单次调用覆盖，`0` 禁用，上限为 `5`。网络错误、429 / 5xx 采用指数退避和抖动；调用方取消可打断等待。429 / 5xx 的有效 `Retry-After`（整数秒或 HTTP 日期）作为最短等待，与退避取较大值；无效提示回退到退避。服务器指定等待时间无法放进剩余预算时，立即抛出原始错误，保留 HTTP 状态和等待提示；实际取消 / 超时仍有独立分类，并清除计时器；`NsuidMapError.retryAfterMs` 可读取解析后的毫秒数。
- Savanna 的 429 / 5xx 即使带 GraphQL `errors` 也按 HTTP 暂时失败处理。其他 GraphQL 错误、其他 4xx、异常成功响应、超时和调用方取消不重试。Redirector 的 200 / 404、没有商品的跳转不重试，缺少 Location 的跳转直接报错；只使用响应头，主动释放响应体。
- HTTP 200 的 JSON 外层及 `data` 必须为对象，`errors` 若存在必须为对象数组。异常返回 `NsuidMapError(kind: 'response')`，不会抛普通空对象访问错误；此处不进行完整商品 schema 校验。
- 单次 `timeoutMs` 同时覆盖 Savanna 和 Redirector；两个上游的重试及退避都共享各自请求的预算。多步映射的总时长可能更长，调用方可传入 `AbortSignal` 控制整个操作。

若调用方自行缓存映射结果，升级这次匹配规则后应清除旧 DLC / 合集结果或变更缓存版本，避免继续使用此前的错误映射。本库没有缓存可自动清除。

`timeoutMs` 只接受 1–120000 的整数毫秒，小数及超范围值直接抛出 `TypeError`，不静默截断或封顶。两个上游在请求前及响应返回后检查取消，Savanna 读取响应体成功后也检查；已缓冲的成功响应不能覆盖已发生的取消或超时。取消保持 `kind: 'abort'`，请求期限届满保持 `kind: 'timeout'`，均不重试。

## 未映射原因

| 情况                     | 提示及含义                                                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| 源商品未返回             | `source NSUID was not returned`；本次源区目录省略该商品，不等同于识别为不支持类型                           |
| 目标 AppID 未解析        | `application ID could not be resolved`；可能未上架或使用另一地区 AppID，当前无法区分                        |
| 跳转有编号、身份没有本体 | `No title identity was returned`；区别于已有本体但平台 / 权益不一致                                         |
| 父商品未返回候选         | `No DLC candidates` / `No bundle candidates`；当前关联及身份查询没有返回候选，不证明该区从未上架            |
| 有候选但不匹配           | `No ... SKU matches`；已有候选，但没有匹配所需身份的商品                                                    |
| 多个候选匹配             | `Ambiguous ... SKU`；现有字段无法唯一决定商品，拒绝任选一条                                                 |
| 扫描未完成               | `candidate scan incomplete`；上限 / 分页截断或提前空页造成未完成，不接受部分结果；父 AppID 无跳转不属于此项 |

提示仅描述实际可见的证据，不能把未发现商品写成确定的停售 / 未上架结论。`reason` 是人类可读文字，不是稳定错误码；调用方以是否返回 `nsuid` 判断成功，不解析整段文字。网络、权限、schema、取消等错误继续抛出异常，不混入业务未匹配结果。
