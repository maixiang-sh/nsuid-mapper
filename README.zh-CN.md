# nsuid-mapper

[English](README.md)

在其他国家的任天堂 eShop 里找到同一个商品。

本项目是非官方工具，与任天堂没有关联，也未获其认可。

## 要解决的问题

任天堂 eShop 的每个商品都有一个 **NSUID**，即 14 位的商品编号。同一款游戏在不同国家的编号通常不一样：

| 街头霸王 6 | NSUID            |
| ---------- | ---------------- |
| 日本       | `70010000095202` |
| 美国       | `70010000095203` |
| 英国       | `70010000095204` |
| 香港       | `70010000095206` |

任天堂没有提供"这个商品在别的国家是哪个编号"的查询方式。本项目就是回答这个问题，支持游戏本体、DLC、合集和体验版。

## 原理简述

本项目组合了任天堂的两个公开服务：

1. 任天堂的商品数据服务（名为 **Savanna**）能告诉我们一个商品是什么：它的游戏编号、平台，以及具体包含哪些内容。
2. 任天堂的一个**跳转链接**能把游戏编号转到任意国家的商品页，而页面地址里就带着该国的 NSUID。

本项目先在源国家读取商品信息，再通过跳转链接找到目标国家的商品，读取它们的信息，只有在恰好一个商品与源商品完全一致时才返回结果。不按名称匹配。

每一步怎么做、每个任天堂服务起什么作用，见[原理说明](docs/how-it-works.zh-CN.md)。

## 快速开始

需要安装 [Bun](https://bun.sh)。本项目运行时不依赖任何第三方库。

```bash
git clone https://github.com/maixiang-sh/nsuid-mapper.git
cd nsuid-mapper
bun install
```

```ts
import { NsuidMapper } from './src/index.ts';

const mapper = new NsuidMapper();
const result = await mapper.mapNsuid('70010000095202', {
  from: 'JP',
  to: ['US', 'GB', 'HK', 'KR'],
});
console.log(result.targets);
```

```js
[
  { region: 'US', nsuid: '70010000095203' },
  { region: 'GB', nsuid: '70010000095204' },
  { region: 'HK', nsuid: '70010000095206' },
  {
    region: 'KR',
    code: 'unresolved',
    reason: 'The application ID could not be resolved in the target region; …',
  },
];
```

每个目标国家要么有 `nsuid`，要么有 `code` 和 `reason` 说明为什么没有。程序里请判断 `code`；`reason` 是给人看的说明。

在其他项目中使用时，先运行 `bun run build`，再把本目录作为名为 `nsuid-mapper` 的本地依赖加入。本项目不发布到 npm。

## 能映射哪些商品

| NSUID 开头     | 商品类型       | 是否支持                                     |
| -------------- | -------------- | -------------------------------------------- |
| `7001`         | 游戏本体       | 支持                                         |
| `7005`         | DLC            | 支持                                         |
| `7007`         | 合集           | 支持                                         |
| `7003`         | 体验版         | 支持，前提是所属游戏在该平台只列出一个体验版 |
| `7009`         | 消耗品         | 不支持，例如游戏内货币                       |
| `7002`、`7008` | 兑换券、课程券 | 不支持                                       |

有些商品即使两个国家都有，也映射不了。这时结果会说明原因，而不是猜一个：

- **游戏在不同地区用了不同的编号**。例如《怪物猎人 崛起》在日本和香港是一个编号，在美国和欧洲是另一个。
- **几个商品在任天堂的数据里完全一样**，例如解锁相同内容的几个 DLC。
- **商品在目标国家已经停售**。任天堂的商品列表不包含已下架的商品，所以找不到。

## 支持的国家

支持 45 个国家，包括日本、香港、美国、加拿大、墨西哥、巴西、英国、澳大利亚、新西兰和欧洲大部分国家。韩国、台湾、中国大陆、东南亚、海湾国家和部分拉丁美洲国家不支持，因为任天堂的跳转链接在这些地方不会跳到商品页。

国家用两位字母代码表示，例如 `JP`、`US`、`GB`。一次调用把一个商品映射到最多 8 个国家。

## 常用选项

```ts
const mapper = new NsuidMapper({
  timeoutMs: 15_000, // 每次请求任天堂的超时时间，默认 10 秒
  retries: 2, // 遇到网络错误或服务器繁忙时额外重试的次数，默认 2 次
});

await mapper.mapNsuid('70070000040805', {
  from: 'HK',
  to: ['JP', 'US'],
  signal: AbortSignal.timeout(30_000), // 整次调用的时间上限
});
```

请求任天堂失败且重试用完后，会抛出 `NsuidMapError`。全部方法、选项、结果代码和错误类型见[参考文档](docs/reference.zh-CN.md)。
